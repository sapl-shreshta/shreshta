🧠 From One Case to a General Rule

Here's the secret trick mathematicians use to turn ONE example into a rule that works forever. There are 3 steps: (1) find how much the sequence grows by each time, (2) use the very first term to pin down the rest of the rule, (3) double-check it against the other terms.

📖 Let's crack this sequence together, step by step: 6, 8, 10, 12, ...

Step 1 — Find the growth step. Tap each ? gap below to reveal how much the sequence jumps by:

🎯 Every gap is +2! That constant growth step becomes the number multiplying n in our rule — so the rule must look like 2 × n + ___.

Step 2 — Use the first term to find the missing piece. When n = 1, the sequence value is 6. So:

📝 Quick Recap

  • 🔢 A pattern is a sequence that follows a hidden rule.
  • ⬡ We can write that rule using a variable, like n, to describe the nth term.
  • 🧠 To find the rule: spot how much it grows by each time, then check it against the first case.
  • 🌍 Patterns hide everywhere: nature, geometry, money, even seating in a classroom!
