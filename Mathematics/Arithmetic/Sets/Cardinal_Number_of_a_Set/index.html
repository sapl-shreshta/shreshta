Cardinal Number of a Set

Counting how many elements are inside!

🧮

Hi again! I'm Sunny the Sorter 👋 Now that you know what a set and its elements are, let's learn a super quick skill: counting exactly how many elements live inside a set. Ready? Let's count what's inside!

🔢 What is n(A)?

The cardinal number of a finite set A, written n(A), is simply the number of distinct (different) elements in A. To find it, just list the set out and count!

A = {a, b, c, d, e}
There are 5 distinct letters, so n(A) = 5
B = {x | x ∈ W, x < 7}
B = {0, 1, 2, 3, 4, 5, 6} → n(B) = 7
P = letters of the word QUEEN
P = {Q, U, E, N} → n(P) = 4
🔍 Careful! Even though the letter E appears TWICE in the word "QUEEN", it is written and counted only ONCE in the set — sets never repeat elements!

⚠️ Special Cases

A few cardinal numbers are worth remembering by heart:

n(φ) = 0
The empty set has zero elements — nothing to count!
Singleton set → n(A) = 1
A singleton set always has exactly one element.
Infinite set → n(A) is UNDEFINED
You can never finish counting an infinite set, so it has no cardinal number.

🧮 Worked Example

Let D = {x | x is a digit in the numeral 11056771}. Let's find n(D) step by step.

Step 1: List the digits as they appear
1, 1, 0, 5, 6, 7, 7, 1
Step 2: Write as a SET (no repeats!)
D = {1, 0, 5, 6, 7}
Step 3: Count the distinct elements
n(D) = 5
📌 The digit 1 appears three times and 7 appears twice in 11056771 — but in the set D, each is counted only once. That's why n(D) = 5, not 8!
