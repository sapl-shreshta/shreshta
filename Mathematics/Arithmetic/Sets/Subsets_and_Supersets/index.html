Subsets & Supersets

When one set lives entirely inside another!

🧮

Hi again! I'm Sunny the Sorter 👋 Did you know sets can hide inside other sets, like a smaller box tucked inside a bigger one? Today we'll learn exactly how to spot when that happens, and the special names we give those set pairs!

🔗 Subset (⊂)

A set A is called a subset of set B — written A ⊂ B — if every single element of A is also an element of B. Every member of A must find a match inside B, with no exceptions.

A = {2, 3, 5}
B = {1, 2, 3, 4, 5, 6}
A ⊂ B, since every member of A (2, 3, and 5) is found in B.
🧠 Think of it like: a small toy box (A) that fits completely inside a big toy chest (B) — nothing from the small box sticks out!

📦 Superset (⊃)

The same relationship can be read the other way round. If A ⊂ B, we also say that B is a superset of A, written B ⊃ A. B is the bigger set that "contains" A.

A ⊂ B
"A is a subset of B"
B ⊃ A
"B is a superset of A"
📌 A ⊂ B and B ⊃ A mean exactly the same thing — just told from two different points of view!

B ⊂ A — every element of B sits completely inside A, with room to spare!

⚠️ Key Properties

A few important rules always hold true for subsets:

  • Every set is a subset of itself: A ⊂ A, always.
  • The empty set is a subset of every set: φ ⊂ A, for any set A.
  • A ⊄ B means A is NOT a subset of B — there is at least one element of A missing from B. Example: A = {2, 3, 5}, B = {1, 2, 4, 6}: since 3 ∉ B, we get A ⊄ B.

➰ Proper Subset

Here's a useful refinement: if A ⊂ B AND A ≠ B (meaning B has at least one extra element that A doesn't have), then A is called a proper subset of B.

A = {1, 2, 3}, B = {1, 2, 3, 4}
A is a proper subset of B — B has the extra element 4 that A is missing.
A = {1, 2, 3}, B = {1, 2, 3}
A ⊂ B still holds (every set is a subset of itself), but A is NOT a proper subset of B — there's no extra element in B.
📌 The key idea: a proper subset must be strictly smaller — missing at least one element that the bigger set has.

📋 Listing All Subsets of a Set

Let's list every possible subset of A = {1, 2, 3} — including the tiniest one and the biggest one!

φ
The empty subset
{1}, {2}, {3}
Subsets with one element each
{1,2}, {1,3}, {2,3}
Subsets with two elements each
{1,2,3}
The whole set itself
📌 Counting them up: φ, {1}, {2}, {3}, {1,2}, {1,3}, {2,3}, {1,2,3} — that's 8 subsets in total!

✨ Number of Subsets = 2ⁿ (the Power Set)

Here's a wonderful shortcut: if a set A has n(A) = n elements, then A has exactly 2ⁿ subsets. This complete collection of all the subsets of A is called the Power Set of A.

{1, 2, 3}
n = 3 elements → 2³ = 8 subsets ✓ (matches our list above!)
{a, b}
n = 2 elements → 2² = 4 subsets: φ, {a}, {b}, {a,b}
💡 No need to list every subset by hand — just count the elements (n) and work out 2ⁿ!
