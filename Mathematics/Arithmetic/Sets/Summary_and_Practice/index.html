📊 Quick Reference Table

Every symbol you've met in Sets, together in one handy table.

Symbol Meaning Example
∈ belongs to e ∈ V (e is a vowel)
∉ does not belong to k ∉ V (k is not a vowel)
⊂ is a subset of {2,3} ⊂ {1,2,3,4}
⊃ is a superset of {1,2,3,4} ⊃ {2,3}
n(A) cardinal number (count of elements) n({a,b,c}) = 3
φ or { } empty / null set n(φ) = 0
∪ union (combine, no repeats) {1,2} ∪ {2,3} = {1,2,3}
∩ intersection (common elements) {1,2,3} ∩ {2,3,4} = {2,3}
− difference (in one, not the other) {1,2,3} − {2,3} = {1}
A′ complement (everything in U except A) if U = {1,2,3,4,5} and A = {1,2}, then A′ = {3,4,5}
↔ equivalent sets (same number of elements) {a,b,c} ↔ {1,2,3}
= equal sets (same elements) {1,2,3} = {3,2,1}

🗂️ Types of Sets at a Glance

A quick recap of every kind of set you've met.

  • Finite set — a limited, countable number of elements.
  • Infinite set — an unlimited number of elements.
  • Singleton set — exactly one element.
  • Empty (null) set — no elements at all, denoted φ or { }.
  • Universal set — the "container" set (U or ξ) holding everything relevant to a problem.
