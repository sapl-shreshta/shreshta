🟢 What Does "Intersection" Mean?

Imagine two friends each write down their favourite colours on separate lists. If someone asked, "Which colours do you BOTH like?" — you'd only write down the colours that show up on both lists. Everything else gets left off. That overlapping bit is exactly what an intersection is!

Formally: the intersection of two sets A and B, written A ∩ B, is the set of elements that appear in BOTH A and B at the same time. If an element is only in one of the sets, it does NOT belong in the intersection.

Numeric example
A = {1, 2, 3, 4}, B = {3, 4, 5, 6}
A ∩ B = {3, 4} — only 3 and 4 are in both sets.
Real-world example
A = students who play cricket = {Ravi, Meena, Karan}
B = students who play football = {Meena, Aisha}
A ∩ B = {Meena} — Meena is the only one who plays both sports.

📝 Step-by-Step: How to Find an Intersection

Follow this simple mini-guide whenever you need to find A ∩ B:

Step 1
Write out both sets in roster form.
Step 2
Go through set A element by element.
Step 3
For each element, check: does it ALSO appear in set B? If yes, keep it. If no, leave it out.
Step 4
Whatever's left over is your intersection!
🔍 Worked example: A = {2, 4, 6, 8, 10}, B = {4, 8, 12}
Check 2 → not in B, skip. Check 4 → in B, keep! Check 6 → not in B, skip. Check 8 → in B, keep! Check 10 → not in B, skip.
A ∩ B = {4, 8}

🚧 Disjoint Sets — When There's NO Overlap At All

Sometimes, when you go looking for the intersection of two sets, you search and search... and find nothing at all! Not a single shared element. This is actually an important and common situation in maths, and it has a special name.

Definition: If A ∩ B = φ (the empty set) — meaning A and B have NO elements at all in common — then A and B are called DISJOINT SETS.

🐾 A relatable analogy: Imagine one friend only owns cats and dogs as pets, and another friend only owns fish and birds. If you compare their pet lists, there is zero overlap in the TYPES of pets they own — none of the same animal type appears on both lists. Their sets of pet types are disjoint.

Let's look at three worked examples so this idea really sticks — including one tricky case where sets look very different but are actually NOT disjoint!

Example 1: Disjoint
A = {1, 2, 3}, B = {4, 5, 6}
Check every element of A against B: Is 1 in B? No. Is 2 in B? No. Is 3 in B? No.
None of A's elements show up in B, so A ∩ B = φ. A and B are disjoint.
Example 2: Disjoint
A = {red, blue, green} (colours)
B = {triangle, square, circle} (shapes)
These sets describe completely different KINDS of things, so obviously nothing overlaps. A ∩ B = φ, disjoint.
Example 3: NOT Disjoint!
A = {2, 4, 6, 8}, B = {1, 3, 6, 9}
Here, 6 appears in BOTH sets! So A ∩ B = {6}, which is NOT empty.
A and B are NOT disjoint — even though most of their elements are different, it only takes ONE shared element to rule out being disjoint.

Here's a visual way to think about it: when two sets are disjoint, their circles in a Venn diagram wouldn't overlap at all — there'd be a gap between them, unlike the overlapping circles you saw earlier for A ∩ B.

A and B are disjoint — their circles don't even touch! There's a gap between them because they share absolutely nothing.
