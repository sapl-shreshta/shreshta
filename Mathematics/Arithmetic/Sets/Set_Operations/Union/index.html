Combining two sets into one big set!

🔵 What Does "Union" Mean?

Imagine you have a box of your own toys, and your friend has a box of their toys. If you tip both boxes into ONE big box — but you never put in a duplicate of a toy you both already had — that combined box is exactly like a union! You end up with one big collection containing everything from both boxes, with nothing repeated.

📖 Formal definition: The union of two sets A and B, written A ∪ B, is the set containing every element that is in A, or in B, or in both — but no element is ever written twice, even if it appears in both original sets.

Example 1 — Numbers:

A = {1, 2, 3}
B = {3, 4, 5}
A ∪ B = {1, 2, 3, 4, 5}
Watch the overlap!
The number 3 was in both A and B, but it appears only once in the union. We never write {1,2,3,3,4,5}.

Example 2 — Real world:

A = students who like pizza
A = {Ravi, Meena, Aisha}
B = students who like burgers
B = {Meena, Karan}
A ∪ B = everyone who likes AT LEAST ONE food
A ∪ B = {Ravi, Meena, Aisha, Karan}
Watch Meena!
Meena likes both pizza AND burgers, but she still only appears once in the union — she's one person, not two!

The shaded region is A ∪ B — everything in A, in B, or in both.

📝 Step-by-Step: How to Find a Union

Here's a simple four-step method you can use every single time you need to find a union.

1
Write out both sets in roster form.
2
List every element from the first set.
3
Go through the second set, and add any element that isn't already listed.
4
That combined list, with no repeats, is your union!
🧵 Worked example: A = {5, 10, 15}, B = {10, 20}

Step 1: The sets are A = {5, 10, 15} and B = {10, 20}.
Step 2: Start with every element of A: 5, 10, 15.
Step 3: Go through B — 10 is already there (skip it), 20 is new (add it).
Step 4: Combine with no repeats: A ∪ B = {5, 10, 15, 20}
